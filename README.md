# Ani Cocoa Cosmetics

The beauty bar and cosmetics shop site for Ani Cocoa Cosmetics in Spintex, Coastal Estates.

```bash
python3 server.py
```

Open [http://127.0.0.1:8090](http://127.0.0.1:8090).

Bookings, shelf requests, and hiring notes are stored in `data/shop.db` on the machine running the server. The site does not take card payments. A service deposit is recorded as acknowledged; the bar still confirms and collects it. The deposit is not refundable.
